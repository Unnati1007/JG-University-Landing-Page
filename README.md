## 🚀 Overview

This project is a complete redesign of the [JG University](https://jguni.in/) landing page. The primary goal was to enhance the UI/UX, modernize the visual aesthetic, and introduce highly engaging, fluid animations to create a premium experience for prospective students.

## ✨ Key Features

- **Modern UI/UX**: Designed using the latest trends including Glassmorphism, deep gradients, and brutalist borders.
- **Fluid Animations**: Heavy utilization of Framer Motion for scroll-linked animations, hover effects, and micro-interactions.
- **Fully Responsive**: Built with a mobile-first approach using Tailwind CSS. Looks perfect on phones, tablets, and large desktop screens.
- **Custom Components**:
  - **Animated Hero Section**: Features a dynamic particle background and a floating car animation.
  - **Hardware Mockups**: An interactive, horizontally-scrollable iPad mockup for the Campus Highlights section.
  - **Staggered Grid Layouts**: Clean, corporate styling for Faculty and Program sections.
  - **Engaging Modals**: Automatic popup for Admission alerts featuring sleek branding.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Running Locally

To run this project on your local machine, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Unnati1007/JG-University-Landing-Page.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **View the application**
   Open [http://localhost:3000](http://localhost:3000) in your browser.
